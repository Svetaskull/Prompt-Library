# Reuse Principles

## One Concept = One Main Idea

Each visual should communicate one primary idea.

Avoid combining several unrelated stories or messages in the same image.

## Adapt Before Creating From Scratch

Before developing a new visual concept, check whether an existing concept can be adapted to the topic.

For example:

**Post-Workout Hydration**

can be adapted for:

- Electrolytes
- Summer workouts
- Recovery
- Sports nutrition
- Hydration content

## Concepts Are Starting Points

These concepts are not fixed prompts.

They should be adapted based on:

- Content topic
- Product
- Audience
- Season
- Platform
- Required composition

Detailed generation requirements and production rules are documented separately in:

`Nana Banana Best Practices.md`
