# Handling Problem Accounts

## Goal

Standard process for handling problematic social media accounts.

---

## Problem Types

### Zero Views

Possible causes:

- Platform restrictions
- Account quality issues
- Device issues
- Content issues

---

### Sudden Reach Drop

Possible causes:

- Algorithm changes
- Account flags
- Content quality

---

### Account Restrictions

Possible causes:

- Policy violations
- Suspicious activity

---

## Investigation Process

Problem detected
↓
Collect information
↓
Check recent changes
↓
Form hypotheses
↓
Test solutions
↓
Document results

---

## Escalation

When to notify management:

- Multiple accounts affected
- Long-term restrictions
- Unknown issues
