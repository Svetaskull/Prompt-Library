# Instagram Carousel Frameworks

Collection of proven carousel structures for educational and marketing content.

---

# Framework 1: Problem → Solution

## Structure

1. Hook
2. Problem
3. Why it happens
4. What to do
5. Key takeaway
6. CTA

## Best for

- Health topics
- Supplements
- Cosmetics
- Sports nutrition

---

# Framework 2: Myth → Fact

## Structure

1. Hook
2. Common myth
3. Why it's incorrect
4. What actually happens
5. Practical recommendation
6. CTA

## Best for

- Vitamins
- Nutrition
- Beauty myths
- Lifestyle topics

---

# Framework 3: Symptoms → Explanation

## Structure

1. Hook
2. Symptom list
3. Possible explanation
4. What can help
5. Key takeaway
6. CTA

## Best for

- Fatigue
- Recovery
- Sleep
- Seasonal topics

---

# Framework 4: Mistakes

## Structure

1. Hook
2. Mistake #1
3. Mistake #2
4. Mistake #3
5. Correct approach
6. CTA

## Best for

- Skincare
- Training
- Supplementation
- Self-care

---

# Framework 5: Quiz

## Structure

1. Question
2. Option A
3. Option B
4. Correct answer
5. Explanation
6. CTA

## Best for

- Engagement
- Educational content
- Awareness campaigns
