# How I Use AI

I do not treat AI output as a finished result.

A typical workflow looks more like:

**Context → AI → Evaluation → Editing → Iteration → Final Output**

For visual work:

**Idea → Visual Concept → Generation → Evaluation → Iteration → Animation**

For operational work:

**Recurring Problem → Analysis → Process → Documentation → Reuse**

AI accelerates parts of these workflows.

Judgment still determines the final result.
