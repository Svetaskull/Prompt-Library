# Prompt Library

A practical knowledge base for AI-assisted content production, content operations, workflow design and team management.

What started as a collection of prompts gradually evolved into a working system for documenting how I use AI, build content workflows, manage processes and turn recurring problems into reusable solutions.

This repository contains not only prompts, but also real workflows, SOPs, templates, case studies, operational frameworks, creative experiments and lessons learned from day-to-day work.

---

## What This Repository Is About

My approach to AI is simple:

> AI is a working tool, not a substitute for thinking.

I use generative AI to accelerate research, structure information, explore ideas, create content, develop visual concepts and improve workflows.

But generation is only one part of the process.

The more important questions are:

- What problem are we solving?
- Where does AI actually save time?
- What still requires human judgment?
- How do we evaluate the output?
- How can a successful solution become a repeatable process?
- How do we prevent the same operational problem from being solved manually again and again?

This repository documents my answers to those questions through real work and experiments.

# Working Principles

### AI accelerates thinking. It does not replace it.

Generated output still needs evaluation, editing and contextual judgment.

### Document what works.

A useful solution becomes more valuable when it can be reused.

### Document what fails.

Failed approaches often contain more reusable information than successful one-shot generations.

### Build systems around recurring work.

Repeated manual decisions are signals that a checklist, template, SOP or workflow may be needed.

### Keep workflows practical.

A sophisticated system that nobody can realistically use is worse than a simple process that works consistently.

### Change tools when necessary.

There is no reason to force one AI model to solve every task.

Model selection is part of the workflow.
