# Decision Making Frameworks

## Framework 1

Will this save time in the future?

If yes:

Document it.

---

## Framework 2

Will this problem happen again?

If yes:

Create a process.

---

## Framework 3

Am I solving the root cause?

Or only the symptom?

---

## Framework 4

Can this be simplified?

Look for the simplest effective solution.

---

## Framework 5

Can this be reused?

Reusable solutions are usually more valuable.
