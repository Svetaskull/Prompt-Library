# Repository Rules

## Before creating a new file

Ask:

1. Does a similar file already exist?
2. Can this information be added to an existing document?
3. Will I actually use this file again?

---

## When to create a new file

Create a new file only if:

- The topic is large enough.
- The topic will grow over time.
- The topic does not fit existing files.
- The information has a distinct purpose or audience.

---

## Preferred Order

1. Update existing file.
2. Expand existing file.
3. Create new section.
4. Create new file.

---

## Knowledge First

Store:

- Observations
- Lessons
- Experiments
- Frameworks

Avoid creating empty documents.
